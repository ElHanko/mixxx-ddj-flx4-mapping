# Contributing

Contributions, feedback and experiments are welcome.

This mapping is primarily developed for my own workflow, but if you find
bugs or have improvements, feel free to open an issue or pull request.

## Reporting issues

If you encounter a problem, please include:

- Mixxx version
- operating system
- description of the controller behaviour
- steps to reproduce the issue

Controller mappings often depend on timing and hardware state, so clear
descriptions help a lot.

## Pull requests

Pull requests are welcome if they improve stability, readability or
controller behaviour.

Please try to:

- keep changes focused
- explain the reasoning behind behaviour changes
- avoid large unrelated refactors

## Commit messages

The project loosely follows a conventional commit style:


type(scope): short description


Examples:


feat(pads): add PAD FX behaviour
fix(loop): correct reloop logic
refactor(vumeter): simplify LED scaling
docs: update README


## Project status

This mapping is **work in progress** and optimized for the author's
workflow. Some design decisions may intentionally differ from the
official Mixxx mapping.
